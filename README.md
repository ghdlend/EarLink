# EarLink

시각장애인, 청각장애인, 일반 사용자가 실시간으로 함께 대화할 수 있는 소통 플랫폼입니다.

## 소개

기존 소통 보조 기술은 시각장애인용(음성/점자)과 청각장애인용(수어/자막)이 각각 따로 존재해, 서로 다른 장애 유형을 가진 사람들이 함께 대화하기 어려웠습니다.
EarLink는 음성, 텍스트, 점자를 실시간으로 연결해 세 사람이 동시에 소통할 수 있는 것을 목표로 합니다.

## 기술 스택

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ESLint

## 시작하기 cmd

npm install
npm run dev


브라우저에서 http://localhost:3000 접속

## 브랜치 전략

- `main` : 배포 가능한 안정 버전
- `dev` : 개발 통합 브랜치
- `feat/*`, `fix/*`, `docs/*` : 기능별 작업 브랜치
